# sample_data — 光伏发电领域资料

3 篇互相关联的中文领域资料，用于演示"知识编译 + wiki 编译"。
故意设计成**概念 / 实体 / 关系交织**，便于抽出丰富本体 + 互链词条：

| 文件 | 主要内容 | 贡献的本体节点 |
|------|----------|----------------|
| `01_solar_pv_principles.md` | 光伏发电原理 | 概念：光伏效应 / 半导体能带 / PN结 / 光电转换效率 |
| `02_solar_pv_components.md` | 光伏系统组件 | 实体：单晶硅电池板 / 多晶硅电池板 / 薄膜电池 / 逆变器 / MPPT控制器 / 储能电池 / 汇流箱 |
| `03_grid_and_storage_comparison.md` | 并网与储能对比 | 关系：单晶 vs 多晶 / 集中式 vs 分布式 / 并网 vs 离网 |

跨文件关系示例（编译后应在本体中出现）：

- `光伏效应` —causes→ `直流电`
- `逆变器` —converts→ `交流电`
- `单晶硅电池板` —is_a→ `光伏组件`
- `MPPT控制器` —part_of→ `逆变器`
- `储能电池` —enables→ `离网系统`

这些都是公开领域常识，无版权约束，可随 cookbook 一起提交。
你可以把这里替换成自己的领域资料（.md / .txt / .pdf / .docx）。
