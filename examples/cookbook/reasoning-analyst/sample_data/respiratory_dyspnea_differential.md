# 资料：急诊呼吸困难的「心源性 vs 肺源性」鉴别

## 背景
急诊呼吸困难需在「心源性」（如急性心衰）与「肺源性」（如肺炎、COPD 急性加重、
肺栓塞）之间做竞争性鉴别。以下为一名发热 + 咳嗽 + 呼吸困难患者的关键数据。

## 病例数据
- 病史：3 天发热、咳黄痰、活动后气促，无夜间阵发性呼吸困难、无端坐呼吸。
- 体征：体温 38.6℃，右下肺局限性湿啰音；颈静脉无怒张，双下肢无水肿。
- 病原学：痰培养检出**肺炎链球菌**；痰涂片见大量革兰阳性双球菌。
- 感染标志物：白细胞、C 反应蛋白（CRP）、中性粒细胞升高；降钙素原（PCT）0.42 ng/mL。
- 影像：胸片示右下肺野斑片状高密度影。
- 心脏指标：BNP 轻度升高但在合并感染时可非特异性升高；超声示左室射血分数正常。

## 鉴别逻辑（ACH 竞争假设要点）
| 证据 | 支持肺源性 | 支持心源性 |
|---|---|---|
| 黄痰 + 痰培养阳性 | 强支持 | 不支持 |
| 发热 + CRP/PCT 升高 | 强支持 | 中性（感染可继发） |
| 胸片斑片影 | 强支持 | 不支持（心衰多为间质水肿/胸腔积液） |
| 颈静脉无怒张、无水肿 | 中性 | 反对 |
| LVEF 正常 | 中性 | 反对 |

## 结论倾向
证据高度一致指向急性肺部感染（社区获得性肺炎），并与典型心衰表现相悖。
临床干预应聚焦抗感染与呼吸支持。
